# בוט תמיכה — Discord

בוט שמקים שרת תמיכה שלם: אימות לפני כניסה, ערוצים, ומערכת טיקטים עם תמליל.

## התקנה

```bash
pip install -U "discord.py>=2.3"
```

צור קובץ `.env` לצד `bot.py`:

```
DISCORD_TOKEN=הטוקן_שלך
```

**אל תשים את הטוקן בקוד ואל תשלח אותו באף מקום.** אם הוא נחשף — Reset Token
ב-Developer Portal.

## הגדרה ב-Developer Portal

תחת **Bot**, הדלק את שני ה-Privileged Intents:

- `SERVER MEMBERS INTENT` — בלעדיו הבוט לא יכול לתת תפקידים, והאימות לא יעבוד
- `MESSAGE CONTENT INTENT` — בלעדיו התמליל יֵצא ריק

תחת **OAuth2 → URL Generator**: סמן `bot` ו-`applications.commands`,
ובהרשאות: Manage Roles, Manage Channels, View Channels, Send Messages,
Manage Messages, Attach Files, Read Message History.

## הפעלה

```bash
python3 bot.py
```

בשרת עצמו, כמנהל, הרץ פעם אחת:

```
/setup
```

**ואז — קריטי:** הגדרות → תפקידים → גרור את תפקיד הבוט **מעל** `מאומת`,
`צוות` ו`מנהל`. דיסקורד לא נותן לבוט להעניק תפקיד שנמצא מעליו, ובלי זה
כפתור האימות ייכשל.

## איך זה עובד

**אימות.** `@everyone` מאבד את הרשאת הצפייה בכל השרת. רק `חוקים` ו`אימות`
גלויים. לחיצה על הכפתור נותנת את התפקיד `מאומת`, וכל שאר הערוצים נפתחים.

**טיקטים.** בערוץ `פתיחת-טיקט` בוחרים סוג מרשימה, נפתח חלון לכתיבת הסיבה,
ונוצר ערוץ פרטי בקטגוריה של אותו סוג — גלוי רק לפותח ולצוות.

בערוץ הטיקט יש שני כפתורים: **אני מטפל** (צוות בלבד, מסמן מי אחראי)
ו**סגור טיקט**. בסגירה נשלח תמליל מלא בהודעה פרטית — לפותח, למי שלקח את
הטיקט, ועותק לערוץ `לוג-טיקטים`.

טיקט אחד פתוח לכל אדם, כדי למנוע הצפה.

## עריכה

- **חוקים, סוגי טיקטים והשאלות** — `rules.py`
- **מבנה הערוצים** — `SERVER_LAYOUT` ב-`bot.py`

אחרי שינוי, הרץ שוב `/setup`. הוא לא יוצר כפילויות — מדלג על מה שכבר קיים
ומעדכן הרשאות.
