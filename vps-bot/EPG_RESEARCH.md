# מחקר לוח שידורים (EPG) — ממצאים ותוכנית

> נשמר ב-27/08/2026. הפרויקט **בהמתנה** עד להשלמת מיפוי מלא של הערוצים.
> אין לפרוס כלום עד שהמיפוי מוכן ונבדק.

## המטרה

לחבר לוח שידורים לערוצי השידור החי (96 ערוצים): מה משודר עכשיו,
מה הבא בתור, לוח מלא. באתר ובאפליקציה. באפליקציה — כפתור "הזכר לי"
ששולח התראת push כשמגיע זמן השידור.

## מקור הנתונים — נפרץ ואומת ✅

**וואלה tv-guide** מגיש לוח שידורים מלא ל-yes ו-HOT דרך API פנימי.
זיהינו אותו מתוך קוד ה-JS של האתר (`window.wallaEnv.DAL_URL`).

### הכתובות

בסיס: `https://dal.walla.co.il/`
כותרת חובה: `Referer: https://tv-guide.walla.co.il/`

| מה | כתובת |
|---|---|
| רשימת ערוצי yes + לוח | `https://dal.walla.co.il/tv/list?provider=3` |
| רשימת ערוצי HOT + לוח | `https://dal.walla.co.il/tv/list?provider=2` |
| לוח ערוץ בודד ליום | `https://dal.walla.co.il/tv/channel?id=<קוד>&date=<YYYYMMDD>` |
| פרטי תוכנית | `https://dal.walla.co.il/tv/program?id=<id>` |
| ז'אנרים | `https://dal.walla.co.il/tv/genre` |

`provider`: 3=yes, 2=hot, 1=ברירת מחדל.

## כיסוי מול הערוצים שלנו

מתוך 96 הערוצים שלנו, **כ-88 יש התאמה אפשרית** בוואלה.
8 ללא התאמה: UFC, זום, C14, i24, הופ!, ערוץ 24, ערוץ 98, WIZ.

**אזהרה:** ההתאמה האוטומטית לפי שם **לא אמינה** — שמות שונים בין
המערכות (למשל "כאן 11" שלנו = "1+1" בוואלה). חובה **מיפוי ידני**
מדויק ערוץ-לקוד. זו הסיבה שהפרויקט בהמתנה.

## מה עוד צריך (לפי סדר)

1. **מיפוי ידני מלא** — טבלה שמחברת כל ערוץ שלנו לקוד וואלה הנכון.
   קבצי עזר: `mapping_template.csv` (הערוצים שלנו) ו-`walla_channels.csv`
   (כל ערוצי וואלה עם הקודים). נמצאים בתיקיית ה-scratchpad.
2. **שירות בשרת** שמושך את הלוח כל כמה שעות ושומר אותו (מטמון),
   כדי לא לפגוע בוואלה בכל בקשת צופה.
3. **תצוגה** — דף שידור חי עם פליי + קטגוריות + לוח למטה, באתר ובאפליקציה.
4. **התראות** — כפתור "הזכר לי". התשתית קיימת: Firebase Messaging
   כבר בשימוש בבוט. צריך רק מנגנון תזמון בשרת ששולח push בזמן.

## דגשים

- וואלה עלול לשנות את ה-API → הלוח יישבר. צריך ניטור.
- המיפוי הוא חד-פעמי אבל דורש דיוק; טעות = תוכניות שגויות לצופה.
- להתחיל בקטן: קודם קומץ ערוצים מדויקים, למדוד, ואז להרחיב.
