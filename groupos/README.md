# GroupOS — שלב 1

מערכת ניהול קהילות לטלגרם. **שירות נפרד מ-zovex בכוונה** — תקלה בבוט
הקבוצות לא אמורה להפיל אתר סטרימינג.

מפת הבנייה המלאה, עם כל ההחלטות והמספרים שנמדדו, נמצאת בארטיפקט שנשלח
בצ'אט.

## מה יש כאן עכשיו

| קובץ | תפקיד |
|---|---|
| `db.py` | סכימה, מיגרציות, גישה למסד |
| `permissions.py` | תפקידים, הרשאות, כלל הדירוג |
| `audit.py` | יומן ביקורת עם מצב לפני/אחרי |
| `ratelimit.py` | שומר המכסות של טלגרם |
| `locks.py` | 32 סוגי נעילה + זיהוי. טהור, בלי טלגרם |
| `moderation.py` | אזהרות, מדיניות, ענישות — ההחלטה, לא הביצוע |
| `panel.py` | מסכי הניהול בפרטי, כנתונים |
| `i18n.py` | כל טקסט שהמשתמש רואה. שפה = מילון |
| `bot.py` | מתאם aiogram — **המודול היחיד שמכיר את טלגרם** |
| `test_core.py` | 180 בדיקות. רצות בלי טוקן ובלי רשת |
| `manifest.txt` | רשימת הקבצים שהמתקין מוריד |

## הכלל שמחזיק את הכל

רק `bot.py` מייבא `aiogram`. הליבה לא יודעת שקיים טלגרם, ולכן:

- הבדיקות רצות בלי טוקן, בלי רשת ובלי קבוצה אמיתית
- אם המערכת תגדל מעבר למה שפייתון נותן, מה שנכתב מחדש הוא `bot.py` בלבד

יש בדיקה שאוכפת את זה דרך ה-AST, לא לפי מוסכמה.

## התקנה

```bash
curl -fsSL -o /tmp/gos.sh https://raw.githubusercontent.com/davidggjg/zovex/claude/hls-relay-schema-port-ll8xiz/groupos/install.sh
bash /tmp/gos.sh
```

המתקין מוריד, **מריץ את הבדיקות לפני שהוא נוגע בשירות**, שומר את הטוקן
ב-`.env` עם הרשאות 600, מתקין שירות systemd עם תקרות זיכרון ומעבד,
ומוודא שהבוט באמת ענה לטלגרם — לא רק ש"השירות רץ".

עדכון קוד בלבד, בלי לגעת בטוקן:

```bash
bash /opt/groupos/install.sh --update
```

שרת Bot API מקומי (מומלץ — מחזיר נתיב מקומי לקבצים במקום להוריד אותם)
מוגדר דרך `GROUPOS_API_BASE` ב-`.env`.

**הטוקן לעולם לא נכנס למאגר.** הוא יושב רק ב-`/opt/groupos/.env`.

## בדיקות

```bash
python3 test_core.py
```

להריץ **לפני כל שינוי בליבה**. הן כבר תפסו שלושה באגים אמיתיים:
מיגרציה שיצרה טבלה קיימת, מפצל SQL שנשבר על נקודה-פסיק בתוך הערה
בעברית, ורשימת קבצים קשיחה במתקין שהשמיטה שלושה מודולים — ולכן הפאנל
הפרטי מעולם לא הגיע לשרת.

## הניהול הוא בפרטי

`/start` בצ'אט הפרטי → רשימת הקבוצות שאתה מנהל → כפתורים:

- **נעילות** — 32 סוגים בארבע קבוצות. לחיצה מחליפה: כבוי ← מחיקה ← אזהרה ← השתקה ← חסימה
- **אזהרות** — בחירת מדיניות בלחיצה
- **יומן** — עשר הפעולות האחרונות
- **הגדרות** — ניקוי אוטומטי ומצב שקט
- **שפה** — בורר שפה לקבוצה

אין צורך לשלוח פקודה בקבוצה כדי לנעול אותה.

## פקודות בקבוצה

הן קיימות למי שמעדיף אותן, ו**נמחקות אחרי ניקוי אוטומטי** יחד עם התשובה.
הרשימה נרשמת אצל טלגרם בתפריט ✏️ — לכל שפה בנפרד.

| פקודה | הרשאה |
|---|---|
| `/ban [זמן] [סיבה]` | `user.ban` |
| `/mute [זמן] [סיבה]` | `user.mute` |
| `/kick [סיבה]` | `user.kick` |
| `/unban` `/unmute` | `user.unban` / `user.unmute` |
| `/warn [סיבה]` `/unwarn` `/warns` | `user.warn` |
| `/purge` | `chat.purge` |
| `/role <תפקיד>` | `roles.assign` |
| `/lang` | `settings.write` |
| `/help` `/id` `/health` `/start` | — |

זמן נכתב כ-`30m`, `2h`, `7d`. כל הפקודות פועלות בתגובה להודעה.

## שפות

כל טקסט עובר דרך `i18n.t(key, lang)`. יש מילון מלא לעברית ולאנגלית,
וחלקי לערבית ולרוסית — מה שחסר נופל לאנגלית, ואף פעם לא לשגיאה.

השפה נבחרת כך: שפת הקבוצה אם מנהל קבע אחת, אחרת שפת הטלגרם של המשתמש,
אחרת עברית. **הוספת שפה היא מילון אחד ב-`i18n.py`** — אין קוד לגעת בו.
בדיקה אוכפת שעברית ואנגלית מכסות בדיוק את אותם מפתחות, ושכל מסך נבנה
בכל שפה שיש לה מילון.

## מה נאכף אוטומטית

נעילה שמופרת → ההודעה נמחקת, נרשמת ביומן, ומופעלת הפעולה שהוגדרה.
מנהלים ומנחים פטורים. ב**מצב שקט** (ברירת מחדל) אין הודעה בקבוצה.

## תפקידים

`member` → `helper` → `moderator` → `bot_manager` → `admin` → `super_admin` → `owner`

פעולת ניהול על משתמש אחר מותרת רק כשדירוג המבצע **גבוה** משל היעד. לכן
מנהל לא יכול לחסום מנהל אחר, ואף אחד לא יכול לחסום את עצמו.

כל קבוצה יכולה לדרוס כל הרשאה לכל תפקיד דרך `role_grants`, בלי לגעת בקוד.

## מה הלאה

שלב 2 — הגנה: Ban/Mute/Kick, Warns עם Policy, Purge, Locks, Blocklist,
Anti-Evasion, Flood, Raid, CAPTCHA.

הסכימה של שלבים 2–3 כבר קיימת (`notes`, `filters`, `locks`, `blocklist`,
`allowlist`), כדי שלא נעשה מיגרציה על מסד חי.
